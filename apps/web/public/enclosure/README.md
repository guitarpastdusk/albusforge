# public/enclosure/

Mock-mode assets for the enclosure viewer (`src/components/enclosure/`).

- `fixture.glb` — generated by `scripts/make-enclosure-fixture.mjs`; nodes `base`, `lid`, `parts/{board,battery,probe_connector}`.
- `fixture.png` — the static fallback shown without WebGL: a screenshot of the viewer (Exploded, parts shown).

Live mode doesn't use these: real bodies come from the M5.5 body endpoint once it exists.
