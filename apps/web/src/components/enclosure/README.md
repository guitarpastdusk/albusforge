# src/components/enclosure/

The 360° enclosure viewer — M5.5 in `docs/ASK-TO-ENCLOSURE.md` §6.

- `EnclosurePreview.tsx` — the card (client, no three.js): Base / Lid / Exploded, Show parts, Reset view, and the stage's loading, error (service-unavailable style, Try again) and static-image states. Loads the 3D stage with `next/dynamic` and `ssr: false`. `preview` null renders a placeholder and fetches nothing. `BuildConversation` reads `GET /v1/builds/:id/body` once the ready card is due (`useEnclosureBody`, `actions/enclosure.ts`); until it answers with a body, the card gets the fixture marked `sample` and labels it a sample enclosure (`fixture.ts`, docs/DEMO-ASSUMPTIONS.md); a failed read shows a message and a retry instead.
- `EnclosureCanvas.tsx` — the 3D stage, the only component that imports three.js (via `scene.ts`). Focusable: arrow keys orbit, + / − zoom; OrbitControls handles mouse and touch.
- `scene.ts` — renderer (started first: no WebGL 2 → `RendererUnavailableError`, before any download), abortable model fetch (`ModelLoadError`), GLTFLoader, lights, OrbitControls, views (`applyView`), keyboard orbit, and disposal that releases the WebGL context (`forceContextLoss`) and every geometry, material, texture and bitmap once (`disposeObject`). Expects GLB nodes `base`, `lid`, and optional `parts` with child meshes (GLTFLoader strips `/` from names, so parts are children rather than `parts/*` names).
- `EnclosureFrame.tsx` — the white card and the view pills, shared by every state.
- `EnclosureDialog.tsx` — the modal (background `inert` while open and restored after, focus in, Tab trapped, Escape and backdrop close, focus returned) and the device-ready card's "View enclosure in 3D →" button.
- `modes.ts` — views, the WebGL 2 probe (three.js r186 needs WebGL 2), the typed renderer and model failures, and when to show the static image: no WebGL 2, a renderer that won't start, or auto-rotate (off by default) with reduced motion. A model download failure is the retryable error instead.
- `fixture.ts` — mock mode's preview: `/enclosure/fixture.glb` and `/enclosure/fixture.png` (`public/enclosure/`), regenerated by `scripts/make-enclosure-fixture.mjs`.

`bundle-isolation.test.ts` fails if a page's static import graph reaches three.js.
